# Changelog

## v0.14.0 — 2026-11-04

- Tride 0.14.0 writes format 0.74 (0.13.x wrote 0.72): a `.trd` is now the scene description (`manifest.json`) and its `assets/`, with no `scene.gltf` copy of the scene inside. A file saved by this release needs Tride 0.14.0 or later on every player; an older editor or player refuses it with the "newer format" error that asks to update Tride (TrideKit 0.5.0 says instead that the file has no `scene.gltf`, and the web player 0.5 to 0.8 reports a parse error). glTF stays an import format: a tool that read `scene.gltf` out of a `.trd` finds none.
- Files saved by any earlier release, the oldest released form included, open in the editor and on every player and are converted as they open: their scene, maps, clips and skins are read once from the old file's glTF copy, and the editor saves them in the new form. What cannot be converted is listed as a problem and the rest of the scene opens. A skinned model saved by editor 0.11 to 0.13 lost its skeleton when it was saved; opening it now says so, and importing the source model again brings the skeleton back.
- A material keeps every glTF map: metallic-roughness, normal and occlusion join base colour and emission, each with its UV set and texture transform, and a map's placement and strength can be keyed and bound.
- A node keeps its rotation angles as they were typed (Y 400 stays 400) beside its quaternion: the editor shows them again after the file is reopened, and an axis without keys keeps that angle on every player while the other axes animate. Before, each player could pick other angles for the same pose, up to 180 degrees apart.
- Render settings that leave out tone mapping now draw in ACES Legacy on every player and in the editor, as a scene with no render settings already did; before, players drew such a scene in ACES while the editor drew it in ACES Legacy, so its whites differed. A scene that names its tone mapping looks the same as before.
- A perspective camera saved without a vertical field of view now draws at 60 degrees, as the web player draws it and as taps and Look at Camera already aimed; before, the view was 45 degrees, narrower than what a tap went through.
- A scene saved by an older version no longer keeps a copy of its glTF data in memory once it is open: less memory on such scenes, with nothing to call. Breaking: `TrideScene.sceneGltfBytes()`, `resourceNames()`, `listNodeMetadata()`, `listCarrierMetadata()` and `TrideNodeMetaEntry` are removed from `TrideCore`; a scene's files are read with `assetBytes(uri:)`.
- `TrideSceneView` builds every scene from the runtime's own description of it: the same frames, less memory on most scenes, and skins of more than 256 joints are drawn. A scene drawn only in part is said once on `subscribeDiagnostics` (subject `partialDraw`) and in `TrideKitScene.partialDrawNotice`, which keeps every reason of the scene's build and starts empty for the next scene. Breaking: the `TrideKitFilamentBridge` library no longer loads glTF: `loadGltfJson`, `loadGlb`, the node setters by glTF name, `setNodeOpacity`, `nodeCastsShadows` and `dressAssetWithMaterialGraphs` are removed, and `TrideFilamentError.assetParseFailed` with them.
- An animated alpha cutoff now cuts the meshes of the scene file as it does on the web, instead of keeping the cutoff the scene was saved with; an animated double side reaches them the same way.
- An object of the scene file whose node material cannot be drawn (its compiled material is missing, out of date, or refused by the device) now draws its plain material, with its colours and pictures, and keys on it keep working; the runtime names the material once. A refusal by the device is reported as `material.package-refused`.
- A material whose animated values turn on what changes its shader (transmission on a material saved without it, double-sided) now draws with the new shader on the meshes of the scene file and keeps every value written so far, instead of reporting a value-shape problem and keeping the old look.
- An orthographic camera fills the view at one uniform scale whatever the view's shape (before, a view of other proportions stretched it), and a tap through it lands on what is shown. A glTF camera with an aspect ratio no longer draws its frame squeezed across.
- Render overrides on a scene that sets no render settings keep the scene's own colour grading, and clearing them returns the view to the scene's own look; before, an override switched the frame to ACES and clearing it left it there.
- Pictures with transparency keep their colour: a PNG the app hands to an image input, and the scene's own see-through maps, no longer turn dark or black where they are transparent.
- Up to five directional lights now light a scene; before, only the brightest one did, so scenes with several suns look different. The brightest casts the shadow and draws the sun disc, the next four light without shadows; a sixth and later sun is not drawn, and the runtime warns once about it, as it does when two suns are equally bright and either could take the shadow. On a test scene with several suns, a frame took 0.52 ms (4.9 %) longer on an iPhone 13 Pro Max.
- An app's code is about 0.97 MB smaller: the glTF loader and the Draco, KTX2 (Basis Universal) and meshopt decoders are no longer linked. Measured on a Release build of the Tride test app for iPhone: 12,894,528 to 11,924,460 bytes of code (`__text`).
